# UrbanRelay AI — Free Deployment Guide

Deploy the **100% working app** for free. Two options below — pick one.

---

## Option 1: Render (Easiest — Recommended)

### Step 1: Push to GitHub
```bash
cd C:\Users\paula\Desktop\sih
git add -A
git commit -m "feat: production deployment config"
git push origin main
```

### Step 2: Create Render Account
1. Go to https://render.com → Sign up (free with GitHub)
2. Click **"New +"** → **"Blueprint"**
3. Connect your GitHub repo `paulabraham-s/urbanrelay_ai`
4. Render auto-detects `render.yaml` and provisions:
   - **Web Service** (free tier) — runs the FastAPI backend + serves frontend
   - **PostgreSQL Database** (free tier, 90 days) — persistent data

### Step 3: Set Environment Variables
In Render Dashboard → your service → **Environment** tab:

| Key | Value |
|---|---|
| `SECRET_KEY` | (auto-generated by Render) |
| `DATABASE_URL` | (auto-linked from PostgreSQL) |
| `CORS_ORIGINS` | `["https://your-app.onrender.com"]` |

### Step 4: Deploy
Render auto-deploys on push. First deploy takes ~5 minutes.

**Your app will be live at:** `https://your-app-name.onrender.com`

### Step 5: Seed the Database
After first deploy, go to **Shell** tab in Render dashboard:
```bash
cd backend
python scripts/seed_demo.py
```

> **Note:** Render free tier spins down after 15 min of inactivity. First request after sleep takes ~30s to wake up. Subsequent requests are instant.

## Option 2: Railway (Best WebSocket Support)

### Step 1: Create Railway Account
1. Go to https://railway.app → Sign up (free $5/month credit)
2. Click **"New Project"** → **"Deploy from GitHub repo"**

### Step 2: Add PostgreSQL
1. In your project → **"New"** → **"Database"** → **"PostgreSQL"**
2. Railway auto-creates `DATABASE_URL` env var

### Step 3: Configure Service
Add environment variables:

| Key | Value |
|---|---|
| `SECRET_KEY` | (generate a random string) |
| `DATABASE_URL` | `${{PostgreSQL.DATABASE_URL}}` (auto-linked) |
| `CORS_ORIGINS` | `["https://your-app.railway.app"]` |
| `PORT` | `8000` |

### Step 4: Set Build & Start Commands
- **Build Command:**
  ```
  cd backend && pip install -r requirements.txt && cd ../frontend && npm install && npm run build && cp -r ../data ./public/data 2>/dev/null; cd ../backend
  ```
- **Start Command:**
  ```
  cd backend && uvicorn app.main:app --host 0.0.0.0 --port $PORT
  ```

### Step 5: Deploy
Railway auto-deploys. Your app: `https://your-app.railway.app`

## Option 3: Fly.io (Most Powerful Free Tier)

### Step 1: Install Fly CLI
```bash
curl -L https://fly.io/install.sh | sh
fly auth login
```

### Step 2: Launch
```bash
cd C:\Users\paula\Desktop\sih
fly launch
```
Choose: **No** for PostgreSQL (use SQLite for demo), **Yes** for internal networking.

### Step 3: Deploy
```bash
fly deploy
```

### Step 4: Set Secrets
```bash
fly secrets set SECRET_KEY=$(openssl rand -hex 32)
fly secrets set CORS_ORIGINS='["https://your-app.fly.dev"]'
```

### Step 5: Open
```bash
fly open
```

> **Free tier:** 3 shared-cpu-1x VMs, 256MB RAM each, 160GB bandwidth/month.

## Troubleshooting

| Problem | Fix |
|---|---|
| "Reconnecting..." on WebSocket | Check `CORS_ORIGINS` includes your deployed URL |
| Map shows no roads | GeoJSON files must be in `frontend/public/data/` at build time |
| Blank page | Run `seed_demo.py` to populate database |
| 502 Bad Gateway | Server may still be building; wait 2-3 minutes |
| Cold start slow (30s) | Normal for free tier; subsequent requests are instant |
